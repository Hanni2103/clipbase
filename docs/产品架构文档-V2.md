# Clipbase V2 产品架构文档

> 版本：V2 · 定位：**AI 知识生命系统（AI Memory OS）**
> 本文档是 Clipbase 的架构总纲，描述产品定位、六层飞轮、数据模型、API 全景、客户端架构与 V2 首页设计。

---

## 1. 产品定位

**一句话**：把你看过的，变成你的。

**不是**「一个收藏资料的地方」，**而是**「一个会学习、会遗忘、会提醒、会成长的 AI 大脑」。

产品心智从「工具」升级为「陪伴型系统」：

> 我拥有一个会学习、会遗忘、会提醒、会成长的 AI 大脑。

核心理念：**收藏不是终点，让知识持续产生价值。**

---

## 2. 六层飞轮

```
收集 → 精炼 → 组织 → 消化 → 创造 → 沉淀
 一键    原子化   场景+   做减法+   成文+   护城河
 分享    卡片    搜索    唤醒      分享    (价值累积)
```

| 层 | 能力 | 现状 |
|---|---|---|
| 收集 | 一键分享（网页/公众号/小红书/抖音文案/图片OCR）| ✅ |
| 精炼 | AI 分类 + 原子卡片（要点/步骤/金句/数据）+ 收藏动机 | ✅ |
| 组织 | 场景化 + 语义近似搜索 + 照镜子相似提醒 | ✅ |
| 消化 | 半衰期 + 生命周期 + 主动唤醒(recall) + 做减法(expired) + 静音 | ✅ |
| 创造 | 一键成文（7 种类型）+ 周报 | ✅ |
| 沉淀 | 价值累积（dedup_actions 学习数据 + 原子化知识体系）| ✅ |

## 3. 数据模型（5 张表）

### items（收藏条目）
```
id, user_id, source_platform, original_url, title, raw_text, images,
content_hash,        -- 精确去重
similar_items,       -- 照镜子结果（JSON）
category, tags, summary, confidence,
intent,              -- 收藏动机：do_it/insight/material/inspiration/fun
half_life,           -- 半衰期（天），按分类预设
digest_state,        -- unread/read/digested/internalized
last_recalled_at,    -- 上次召回时间
scene_id,            -- 所属场景
cover_url, status, error_msg, created_at, updated_at
```

### atoms（原子卡片）
```
id, item_id, type(key_point/step/quote/fact), content, sort
```

### scenes（场景，活的、可自动归档）
```
id, user_id, name, emoji, status(active/archived), auto_expire_at, created_at
```

### user_prefs（用户偏好）
```
user_id, muted_topics, remind_frequency, timezone
```

### dedup_actions（照镜子动作，喂给系统学习）
```
id, user_id, item_id, similar_item_id, similarity, action(review/create_scene/keep/mute), created_at
```

## 4. API 全景

### 收集
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/ingest` | 分享入口，返回 item_id + 精确重复 similar |

### 条目
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/items` | 列表（category/tag/q/scene_id 筛选）含原子+相似 |
| GET | `/api/items/:id` | 详情含原子+相似 |
| PATCH | `/api/items/:id` | 改分类/标签/动机/消化状态 |
| POST | `/api/items/:id/retry` | 重新入队 |
| POST | `/api/items/:id/scene` | 归入/移出场景 |
| POST | `/api/items/:id/similar-action` | 照镜子动作（review/create_scene/keep/mute）|
| POST | `/api/items/:id/recall` | 记录召回时间 |

### 场景
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/scenes` | 场景列表（含计数，自动归档过期场景）|
| POST | `/api/scenes` | 建场景（可选 auto_expire_at）|
| POST | `/api/scenes/:id/archive` | 归档 |
| GET | `/api/scenes/suggestions` | 场景建议（分类聚合计数）|

### 消化
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/recall` | 主动唤醒（待回顾，按召回分排序，排除已消化/已静音）|
| GET | `/api/expired` | 做减法（过期建议归档，recall_score < 0.25）|

### 洞察 / 首页
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/dashboard` | 首页聚合：total/today_ingested/today_review/today_awaken/expiring_soon/brain_health/lifecycle/awakening/recent |
| GET | `/api/insight` | AI 洞察：找相似度最高的两条知识，返回关联百分比 |

### 创造
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/compose` | 一键成文（type 参数，7 种）|
| GET | `/api/compose-types` | 7 种创作类型列表 |
| GET | `/api/weekly` | 周报（最近 7 天收藏提炼）|

### 搜索 / 偏好
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/search` | 语义近似搜索（n-gram + 关键词）|
| GET/PATCH | `/api/prefs` | 用户偏好（静音主题/提醒频率/时区）|

## 5. 后端架构

```
server.ts           入口（Express + 静态托管 + 0.0.0.0 监听）
routes.ts           REST 路由（20+ 端点）
pipeline.ts         异步队列（提取 → 分类/精炼 → 相似检测 → 存储）
db.ts               SQLite 存储 + 自动迁移（node:sqlite）
├─ extractors/      提取器（可插拔）：web/wechat/douyin/xiaohongshu/bilibili/image
├─ classifier/      分类+精炼+动机（prompt/mock/LLM 结构化输出）
├─ similar.ts       相似度（哈希 + 字符 n-gram + 标签重合，三级判定）
├─ halflife.ts      半衰期预设 + 召回分衰减
└─ composer.ts      7 种创作类型（LLM 合成）
```

**关键设计**：
- 一次 LLM 调用并行产出「分类 + 原子卡片 + 动机」（省 token）。
- 相似度用「哈希（精确）+ n-gram（近一样）+ 标签重合（同主题）」三级，零外部依赖。
- 半衰期按分类预设（资讯 3 天 / 财经娱乐 7 天 / 方法类 60 天 / 默认 30 天）。
- 召回分 `0.5^(天数/半衰期)` 指数衰减，驱动主动唤醒 + 做减法。

## 7. V2 首页设计（AI 大脑）

**核心理念**：用户打开 App，看到的不是「收藏数量/搜索框/文件列表」，而是「**我的 AI 大脑今天怎么样**」。

结构（自上而下）：
1. **AI 大脑核心球（Knowledge Core）**：渐变光环 + 🧠 + 记忆健康度 % + 正在成长，脉冲发光动效。
2. **Brain Health**：健康度进度条 + 「+N 今日提升」+ 原因（✓学习/✓复习/✓连接）。
3. **三统计卡**：知识容量 / 今日吸收 / 等待整理（数字滚动动画）。
4. **AI 状态（Memory Status）**：🟢活跃记忆 / 🟡即将遗忘 / ⚫沉睡知识。
5. **AI 今日建议**：🧠 AI 发现知识关联（「《A》和《B》存在 92% 关联」）+ 建立连接。
6. **Brain Activity**：+N 新知识 / +N 复习 / -N 沉睡 + 成长轨迹条。
7. 顶部标语：「你的 AI 大脑正在成长」。

**配色（深色 AI 宇宙）**：
- 背景 `#050816`，卡片 `rgba(255,255,255,0.05)`
- 紫 `#8B5CF6`（AI）、记忆蓝 `#06B6D4`、成长绿 `#10B981`、警告 `#F59E0B`

**脑健康度公式**：`brain_health = round(100 × (活跃 + 需复习) / 总数)`。
